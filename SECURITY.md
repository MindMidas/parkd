# Security policy

Parkd is a test-data-only portfolio demo. Do not submit real payment details,
parking-access information, or sensitive personal data.

## Reporting a vulnerability

Do not disclose vulnerabilities through demo content or a public issue. Use
GitHub's private security-advisory flow:

[Open a private security advisory](https://github.com/MindMidas/parkd/security/advisories/new).

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Do not include real credentials or personal data. The repository
owner will acknowledge and triage reports through the private advisory.

## Scope

Supported security fixes target the current `main` branch and the documented
portfolio deployment. Historical branches and unsigned development builds are
not supported releases.
